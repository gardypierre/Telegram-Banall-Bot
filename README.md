# Banall Bot

Telegram Ban all Bot Which can Remove All members easily ...

## Local Development

1. Copy `.env.example` to `.env` and fill in:
   - TELEGRAM_TOKEN (already set)
   - TELEGRAM_APP_ID and TELEGRAM_APP_HASH from https://my.telegram.org
2. `pip install -r requirements.txt`
3. `python -m Banall.bot`

Note: Bot must be admin with ban rights in target group. Pyrogram 2.0 may require minor code updates in bot/__init__.py if errors occur (e.g., iter_chat_members -> get_chat_members).
